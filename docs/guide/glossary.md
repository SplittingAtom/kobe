# Glossary

## Agent

An AI assistant with a model, instructions and tools. Your team can have several.

## Thread

One conversation with an agent. Threads are listed in the left rail. To begin one, see
[Getting started](getting-started.md).

## Sandbox

The isolated machine an agent works in. Secrets never enter it.
